## Regras comuns

**Branch e merge** (memória `branch-integracao-rebranding`):
- Tudo nasce de `feature/rebranding-app`. Branch da feature: `feature/usage-metrics`. Cada tarefa roda em worktree
  próprio com branch `um/t<N>` saído do topo de `feature/usage-metrics`; aprovada no gate, entra por `cherry-pick`.
- Fim de cada fase: gate completo + revisão convergida → `git merge --no-ff feature/usage-metrics` **local** em
  `feature/rebranding-app`. **Sem push** sem o dono pedir.
- `git add` só com caminhos explícitos; rascunhos do dono fora de qualquer commit (`.specs/features/plans-modal/`,
  `docs/mensagens-interativas.md`; conferir com `git status` no início de cada fase). `git show --stat HEAD` depois de cada commit.
- Um commit por tarefa, `tipo(escopo): descrição` + `Co-Authored-By`. Migration nova nunca edita migration aplicada;
  timestamp maior que a última do topo (hoje `20261117140000_add_saver_contacts_phone_pattern_index`; reconferir no início de cada fase).
- **Versões:** próxima minor acima do topo no início de cada fase (topo em `def8d264`: api 0.101.0 · app 0.124.0 →
  P1 previsto api 0.102.0 · app 0.125.0, P2 0.103.0 · 0.126.0, P3 0.104.0 · 0.127.0; reconferir no início de cada fase, outra feature pode ter usado).
  `package.json` + `CHANGELOG.md` da raiz (e `api/CHANGELOG.md` quando a fase tocar a api) juntos. Extensão não muda (sem `manifest`).

**Subagentes e RAM** (memórias `ram-mac-subagentes`, `subagentes-pasta-propria`): até 7 ao mesmo tempo, cada um com
subpasta própria do scratchpad e porta própria; no máximo 1 com Postgres descartável, tarefas `integration-db` em
sequência. Vitest `--maxWorkers=2`; integração `--maxWorkers=1 --no-file-parallelism`. Cada agente recebe só a
própria tarefa, `design.md`, `.specs/codebase/TESTING.md` e os arquivos de `Where`/`Reuses`.

**Segurança:** nunca `api/.env`/`api/.env.dev` (produção); nunca `prisma migrate deploy`/`start:migrate` fora do
descartável; nenhuma escrita no banco de produção; consulta de conferência em produção só `SELECT` agregado com
`statement_timeout`, sem nome, telefone, texto ou e-mail.

**Gates** (`.specs/codebase/TESTING.md`): `quick` = `pnpm test -- --maxWorkers=2` no pacote; `full` = `pnpm typecheck
&& pnpm test -- --maxWorkers=2` em `api/` e `app/`; `integration-db` = `api/scripts/postgres-descartavel.sh start` →
`INTEGRATION_DATABASE_URL=<url> pnpm exec vitest run --config vitest.int.config.mts --project db --maxWorkers=1
--no-file-parallelism` → `stop`; `build` = `pnpm build` no `app/`.

**Revisão** (`/caveman-review`, memória `revisao-sem-loop`): uma por fase, `cavecrew-reviewer` sobre
`git diff feature/rebranding-app...feature/usage-metrics`; só contradição com código ou spec; para quando sobrar só
observação menor. Smoke visual pelo `agent-browser` (claro, escuro, 390 px). Registro em `review.md`.
